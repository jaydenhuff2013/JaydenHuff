A healthy community needs strong moderation. The easiest way to maintain trust is to combine clear rules with role-based permissions and a simple reporting flow.

## Build a role system

Start with a few clear roles:

- **Admin** — full control over server settings and permissions
- **Moderator** — can manage messages, warnings, and reports
- **Member** — can participate in normal community activity

## Use permissions carefully

Only grant higher permissions to the people who need them. This reduces accidental changes and keeps the community stable.

## Add safety tools

- report messages or users quickly
- configure message filters for spam and harmful content
- require verification for new members if needed
- review audit logs for admin actions

## Good moderation habits

- publish a short code of conduct
- warn before taking punitive action when possible
- keep moderation consistent across the community
- escalate serious issues to the admin team
