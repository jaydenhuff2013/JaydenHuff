The Google Apps Discord bot is built around Discord's native slash command system, giving your server a structured, discoverable interface for every feature the bot offers. Whether you're a server admin configuring the bot or a regular member checking server info, every action is just a `/` away.

## How Slash Commands Work

Slash commands are triggered by typing `/` in any text channel where the bot has permission to respond. Discord immediately surfaces an autocomplete menu listing every available command. As you type, the list narrows to matching commands, and once you select one, Discord guides you through each required and optional argument before you hit **Enter** to send.

Because slash commands are registered directly with Discord, they work consistently across the desktop app, mobile app, and the browser client — no extra setup needed on your end.

## Category Reference

| Category | Who Can Use | Description |
|---|---|---|
| **Admin** | Admins & configured roles | Full server management: bans, kicks, mutes, role assignment, and bot configuration |
| **Utility** | All members | Informational and productivity commands available to everyone in the server |
| **Moderation** | Moderators & above | Channel controls, message cleanup, and member discipline tools |

## Command Permissions

By default, admin and moderation commands are restricted to members with the **Administrator** or **Manage Server** Discord permission. Utility commands are available to all members.

You can fine-tune access per command directly inside **Discord's Server Settings → Integrations → Google Apps Bot**. From there, you can restrict any individual command to specific roles or channels, or deny it entirely for certain roles — no code required.

<Note>
  Changes to command permissions in Discord's integration settings take effect immediately and apply to all members. Always test permission changes in a private channel before rolling them out server-wide.
</Note>
