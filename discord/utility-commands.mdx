Utility commands are available to every member in your server and cover everything from checking the bot's connection health to creating polls and setting personal reminders. No elevated permissions are required unless a server admin has explicitly restricted access.

## `/ping`

```
/ping
```

**Description:** Checks the bot's current latency to Discord's API gateway. Useful for confirming the bot is online and responsive.

**Example output:**
```
🏓 Pong!
Latency: 42ms | API: 61ms
```

---

## `/serverinfo`

```
/serverinfo
```

**Description:** Displays a rich embed with statistics and metadata about the current server, including member counts, channel counts, creation date, boost level, and more.

**Example output:**

> **My Awesome Server**
> 👥 Members: 1,204 (1,187 humans · 17 bots)
> 📢 Channels: 24 text · 6 voice
> 🚀 Boost Level: 2 (14 boosts)
> 📅 Created: January 3, 2021

## `/userinfo`

```
/userinfo [user]
```

**Description:** Shows detailed information about a Discord member — account creation date, server join date, roles, and current status. If no user is specified, returns info about the command caller.

| Argument | Type | Required | Description |
|---|---|---|---|
| `user` | User mention or ID | ❌ No | The member to look up (defaults to yourself) |

**Example:**
```
/userinfo @alice
```

**Example output:**

> **alice#0001** (ID: 123456789012345678)
> 📅 Account created: March 12, 2019
> 📥 Joined server: June 5, 2022
> 🎭 Roles: Member, Verified, Early Supporter

## `/avatar`

```
/avatar [user]
```

**Description:** Fetches and displays a full-resolution version of a member's avatar, with a direct download link. If no user is specified, returns your own avatar.

| Argument | Type | Required | Description |
|---|---|---|---|
| `user` | User mention or ID | ❌ No | The member whose avatar to display |

**Example:**
```
/avatar @bob
```
> The bot replies with a full-size image embed and a link to download it in PNG, JPG, and WebP formats.

## `/poll`

```
/poll <question> <option1> <option2> [option3] ... [option10]
```

**Description:** Creates a formatted poll embed with up to 10 answer options. Members vote by clicking the corresponding reaction. The bot tracks votes and can show live results.

| Argument | Type | Required | Description |
|---|---|---|---|
| `question` | String | ✅ Yes | The poll question |
| `option1` | String | ✅ Yes | First answer option |
| `option2` | String | ✅ Yes | Second answer option |
| `option3`–`option10` | String | ❌ No | Up to 8 additional options |

**Example:**
```
/poll "What time should we host game night?" "7 PM EST" "8 PM EST" "9 PM EST"
```

**Example output:**

> 📊 **What time should we host game night?**
> 1️⃣ 7 PM EST
> 2️⃣ 8 PM EST
> 3️⃣ 9 PM EST

## `/remind`

```
/remind <time> <message>
```

**Description:** Sets a personal reminder. When the time elapses, the bot sends you a DM (or mentions you in the channel where the reminder was set, if your DMs are closed) with your message.

| Argument | Type | Required | Description |
|---|---|---|---|
| `time` | Duration string | ✅ Yes | When to send the reminder (e.g. `30m`, `2h`, `1d`) |
| `message` | String | ✅ Yes | The reminder text |

**Example:**
```
/remind 1h30m Check on the community event sign-ups
```
> ⏰ *"I'll remind you in 1 hour and 30 minutes."*

<Note>
  Reminders are delivered as DMs by default. Make sure you have DMs enabled from server members, or the bot will fall back to mentioning you in the channel where you set the reminder.
</Note>

## `/help`

```
/help [command]
```

**Description:** Without an argument, `/help` lists all commands available to you based on your current permissions. Pass a specific command name to get detailed usage instructions for that command.

| Argument | Type | Required | Description |
|---|---|---|---|
| `command` | String | ❌ No | The name of a command to get help with |

**Example:**
```
/help poll
```
> The bot replies with the full syntax, argument descriptions, and an example for `/poll`.

---

## `/roleinfo`

```
/roleinfo <role>
```

**Description:** Displays details about a server role, including its color, creation date, permission flags, number of members assigned, and whether it is mentionable or hoisted.

| Argument | Type | Required | Description |
|---|---|---|---|
| `role` | Role mention or ID | ✅ Yes | The role to look up |

**Example:**
```
/roleinfo @Moderator
```

**Example output:**

> 🎭 **Moderator** (ID: 987654321098765432)
> 🎨 Color: `#ef7025`
> 👥 Members: 8
> 📅 Created: February 14, 2021
> 📌 Hoisted: Yes · Mentionable: No
> 🔑 Key permissions: Kick Members, Manage Messages, Mute Members
