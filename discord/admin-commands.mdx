Admin commands give server administrators and designated moderators direct control over members, channels, and bot behavior — all through Discord's native slash command interface. Every command listed here requires elevated permissions and will not appear in the autocomplete menu for regular members.

## `/config`

```
/config
```

**Description:** Opens an interactive panel to view and change the bot's server-wide configuration, including prefix settings, log channels, welcome messages, and feature toggles.

**Required permission:** `Manage Server`

**Example:**
```
/config
```
> The bot replies with an ephemeral settings panel visible only to you.

## `/ban`

```
/ban <user> [reason] [delete-messages]
```

**Description:** Permanently bans a member from the server. Optionally provide a reason (logged to the audit log and mod-log channel) and choose how many days of message history to delete.

**Required permission:** `Ban Members`

| Argument | Type | Required | Description |
|---|---|---|---|
| `user` | User mention or ID | ✅ Yes | The member to ban |
| `reason` | String | ❌ No | Reason logged to the audit log |
| `delete-messages` | Integer (0–7) | ❌ No | Days of messages to delete (default: `0`) |

**Example:**
```
/ban @spammer Repeated spam in #general delete-messages:1
```
> The member is banned and a confirmation embed is posted to the mod-log channel.

## `/kick`

```
/kick <user> [reason]
```

**Description:** Removes a member from the server without a permanent ban. The member can rejoin via a fresh invite.

**Required permission:** `Kick Members`

| Argument | Type | Required | Description |
|---|---|---|---|
| `user` | User mention or ID | ✅ Yes | The member to kick |
| `reason` | String | ❌ No | Reason logged to the audit log |

**Example:**
```
/kick @newuser123 Joined to advertise
```

## `/mute`

```
/mute <user> <duration> [reason]
```

**Description:** Applies a Discord Timeout to a member for the specified duration, preventing them from sending messages or joining voice channels. Duration accepts human-readable formats such as `10m`, `2h`, or `1d`.

**Required permission:** `Moderate Members`

| Argument | Type | Required | Description |
|---|---|---|---|
| `user` | User mention or ID | ✅ Yes | The member to timeout |
| `duration` | Duration string | ✅ Yes | How long the timeout lasts (e.g. `30m`, `12h`) |
| `reason` | String | ❌ No | Reason logged to the audit log |

**Example:**
```
/mute @troublemaker 1h Excessive caps abuse
```
> Timeout expires automatically after the specified duration.

## `/warn`

```
/warn <user> <reason>
```

**Description:** Issues a formal warning to a member. The warning is stored in the bot's database and the member receives a DM notification (if DM warnings are enabled in [Server Settings](/discord/server-settings)). Warnings contribute to the auto-escalation threshold.

**Required permission:** `Kick Members`

| Argument | Type | Required | Description |
|---|---|---|---|
| `user` | User mention or ID | ✅ Yes | The member to warn |
| `reason` | String | ✅ Yes | Reason for the warning |

**Example:**
```
/warn @member Posting off-topic content in #announcements
```

---

## `/clear`

```
/clear <amount> [user]
```

**Description:** Bulk-deletes messages in the current channel. Optionally filter by a specific user to remove only their messages. Discord limits bulk deletion to messages newer than 14 days.

**Required permission:** `Manage Messages`

| Argument | Type | Required | Description |
|---|---|---|---|
| `amount` | Integer (1–100) | ✅ Yes | Number of messages to delete |
| `user` | User mention or ID | ❌ No | Only delete messages from this user |

**Example:**
```
/clear 50 @spammer
```
> Deletes up to 50 of `@spammer`'s recent messages in the current channel.

<Warning>
  Messages older than 14 days cannot be bulk-deleted due to a Discord API limitation. The command will skip those messages and report how many were actually removed.
</Warning>

## `/slowmode`

```
/slowmode <seconds>
```

**Description:** Sets the slowmode delay for the current channel. Members can only send one message per interval. Use `0` to disable slowmode.

**Required permission:** `Manage Channels`

| Argument | Type | Required | Description |
|---|---|---|---|
| `seconds` | Integer (0–21600) | ✅ Yes | Slowmode delay in seconds; `0` disables it |

**Example:**
```
/slowmode 10
```
> Members in the channel must wait 10 seconds between messages.

---

## `/lock` and `/unlock` {#moderation}

```
/lock
/unlock
```

**Description:** `/lock` prevents regular members from sending messages in the current channel by removing the `Send Messages` permission for the `@everyone` role. `/unlock` restores it. A reason embed is posted in the channel on lock.

**Required permission:** `Manage Channels`

**Example:**
```
/lock
```
> 🔒 A system message is posted: *"This channel has been locked by a moderator."*

```
/unlock
```
> 🔓 The channel is reopened for regular members.

## `/role`

```
/role add <user> <role>
/role remove <user> <role>
```

**Description:** Adds or removes a role from a member. The bot can only manage roles that sit **below** its own highest role in the server's role hierarchy.

**Required permission:** `Manage Roles`

| Argument | Type | Required | Description |
|---|---|---|---|
| `add` / `remove` | Subcommand | ✅ Yes | Whether to add or remove the role |
| `user` | User mention or ID | ✅ Yes | The target member |
| `role` | Role mention or ID | ✅ Yes | The role to assign or revoke |

**Example:**
```
/role add @alice Member
/role remove @bob Verified
```

<Note>
  To prevent abuse, the `/role` command can be restricted to specific roles or channels in **Discord Server Settings → Integrations → Google Apps Bot**. See [Permissions](/discord/permissions) for full details.
</Note>
