The Google Apps dashboard provides a dedicated settings panel for every Discord server the bot is added to. From here, server administrators can customize how the bot behaves — from which channels it logs activity in, to whether it sends DMs when a member is warned or banned — without touching a single command.

## Accessing Settings

To reach your server's settings panel:

1. Log in to the [Google Apps dashboard](https://app.googleapps.example.com).
2. Select your Discord server from the left sidebar under **My Servers**.
3. Click **Settings** in the top navigation bar.

You must have the **Manage Server** permission (or be the server owner) for the settings panel to be accessible. If you see a permissions error, ask your server owner to grant you that permission in Discord.

---

## General Settings

These settings control the bot's overall identity and language within your server.

| Setting | Description | Default |
|---|---|---|
| **Bot Prefix** (legacy) | The text prefix used before commands for bots that do not support slash commands. Only relevant if you have legacy integrations. | `!` |
| **Bot Language** | The language the bot uses for all responses and embeds. Supported: English, Spanish, French, German, Portuguese. | `English` |
| **Bot Nickname** | Override the bot's display name in your server without affecting its global username. | *(none — uses default name)* |

<Note>
  The legacy prefix is only used by integrations that pre-date Discord's slash command system. All current Google Apps commands use `/` and are unaffected by the prefix setting.
</Note>

## Channel Settings

Channel settings define where the bot posts automated messages, logs, and notifications.

| Setting | Description |
|---|---|
| **Log Channel** | The channel where the bot posts moderation actions (bans, kicks, mutes, warns, message deletions). |
| **Welcome Channel** | The channel where new member join messages are posted. Set a custom welcome message template in the text box below this setting. |
| **Mod-Only Channels** | A list of channels where only members with designated moderator roles can use bot commands. Regular members will receive a silent error if they try to use commands here. |

<Note>
  If no log channel is set, moderation actions are still recorded internally but no embed is posted to chat. Setting a log channel is strongly recommended for audit transparency.
</Note>

---

## Notification Settings

Control whether the bot sends direct messages to members when moderation actions are taken against them.

| Setting | Description | Default |
|---|---|---|
| **DM on Warn** | Send the member a DM when they receive a `/warn` action, including the reason provided. | Enabled |
| **DM on Ban** | Send the member a DM with the ban reason before the ban is applied (while they can still receive DMs from the server). | Enabled |
| **DM on Mute** | Notify the member via DM when a timeout is applied, including duration and reason. | Disabled |

## Saving and Applying Changes

<Steps>
  <Step title="Make your changes">
    Adjust any settings you need across the General, Channel, and Notification sections. Unsaved changes are indicated by an orange dot next to the section header.
  </Step>
  <Step title="Review the summary">
    Click **Review Changes** at the bottom of the page. A modal will show a diff of every value you've modified, so you can confirm everything looks correct before committing.
  </Step>
  <Step title="Save settings">
    Click **Save Settings** in the review modal. The dashboard sends the updated configuration to the bot.
  </Step>
  <Step title="Confirm in Discord">
    Head back to your Discord server and run `/config` to verify the new settings are reflected. Most changes apply instantly; bot nickname changes may take up to 60 seconds to propagate.
  </Step>
</Steps>

<Warning>
  Clearing the **Log Channel** field and saving will immediately stop all moderation log embeds from being posted. Make sure this is intentional before saving.
</Warning>
